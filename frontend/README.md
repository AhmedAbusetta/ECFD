# ECFD — Real-Time Security Monitoring Dashboard

* **Owner:** Member 6 (Frontend & DevOps Engineer)
* **Framework:** Next.js 14 / React + TypeScript + Tailwind CSS
* **Communication:** ASP.NET Core SignalR Client

### Running Locally:
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live dashboard.
