Default policy (Egyptian organisation; edit per customer - one file per organisation in ml/brain/policies/):
- Nobody (IT, help desk, bank, manager, vendor, government) ever needs an employee's password, PIN, OTP / verification code, CVV, card number or expiry date by phone.
- The IT help desk resets passwords through a ticket or an emailed reset link; it never asks for the current or old password and never asks the employee to read out a code.
- Banks and wallet providers (InstaPay, Vodafone Cash, Fawry) never ask customers by phone for an OTP, PIN, CVV or full card number, and never ask them to move money to a "safe" or "temporary" account.
- Remote-control software (AnyDesk, TeamViewer, screen sharing) is only installed or opened for a help-desk ticket the employee opened themselves.
- Approving a push notification, MFA prompt or "confirm" message must only happen when the employee started the login or transaction themselves.
- Payments, bank-detail changes and urgent transfers requested by phone must be verified by calling back on an official number from the company directory, never a number the caller gives.
- Callers who are legitimate accept being called back on an official number and do not ask to keep the call secret from colleagues or the branch.
